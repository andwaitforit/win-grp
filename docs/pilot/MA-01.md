## Why this race works as a pilot

- **Live and contested on TV.** Neal survived his closest primary ever on
  Sep 1 (54.0% to Jeromie Whalen's 45.9%). He now faces independent **Nadia
  Milleron**, who took 37% against him in 2024 and was reported in mid-September
  to be putting about **$2M** behind this run.
- **Two backtest windows in one race.** The completed primary (Jul–Sep 1) and
  the live general (Sep 4 – Nov 3). They are also under different LUR windows.
- **Small, bounded market set.** Two DMAs (Springfield-Holyoke and
  Albany-Schenectady-Troy) and roughly 8 stations. Phase 0 can walk every
  relevant political file cheaply.
- **Public reference points already exist.** Local press reported
  station-level primary reservations pulled from FCC files (below), so we can
  sanity-check extraction before the user's ground truth arrives.

**Recommendation: pull cable into the pilot.** Berkshire County and the
Pioneer Valley are heavily cabled, and down-ballot campaigns commonly buy
Spectrum Reach/Comcast zones. Cable political files use the same OPIF
folder API. Leaving cable out would understate GRPs in this race, especially
in the Berkshires, where Neal reportedly spent heavily.

## Polling

Public polling of a single House district is sparse, and VoteHub may have none
for MA-01. The pilot relies on **internal-poll upload** (D5) and shows public
polls whenever any appear.

## Phase 0 tasks for this race

1. Resolve OPIF facility IDs for every station above (and cable systems, if
   pulled in) through the facility search API. Store them in the seed config.
2. Walk `Political Files/2026/Federal/US House/*` and `Non-Candidate Issue Ads`
   on each station. List every purchaser, especially outside groups.
3. Resolve Whalen's FEC IDs. Pull Schedule E independent expenditures that
   name H8MA02041 / H4MA01091. Pull Schedule B media disbursements for
   C00226522 and C00868927.
4. Confirm whether a Republican is on the general ballot.
5. Extract primary-window orders and invoices. Compare them with the reference
   table above.
6. When the user delivers ground truth: run the backtest by window (primary
   vs. general), DMA, and buyer.
